# Omnigent 多角色协作平台 — 测试流程（真实浏览器）

> **方法论（最高优先级）**：所有操作必须基于真实浏览器（agent-browser 可见窗口）。
> 后端 API 验证通过不算数——UI 操作不满足要求，后端再正确都没用。
> 每个环节从浏览器操作，观察页面真实反应。

## 角色
| 角色 | 用户 | 职责 |
|------|------|------|
| 项目经理 | admin | 建项目、配置、分派、监控、评价、重分配、AI 拆分子任务 |
| 项目成员 | zhangsan/wangwu/zhaoliu/lisi | 领取(只能自己的)、执行、提交、评价主任务 |
| Agent | 各成员自己的 pi | 按项目上下文执行任务 / admin 自动拆分 |
