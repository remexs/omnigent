# Omnigent 安装指南（用户版）

> 本文档面向最终用户，按角色说明如何安装和使用 Omnigent。
> 当前服务器：`http://192.168.10.20:8000`（管理员账号 root / 123456）

---

## 一、角色说明

| 角色 | 做什么 | 需要装什么 |
|------|--------|-----------|
| **普通用户** | 用浏览器/桌面端操作界面 | 桌面端（可选）或直接用浏览器 |
| **Host（执行机）** | 跑 AI 任务（agent 执行环境） | omnigent CLI 或 Docker |

> **普通用户不需要装任何东西**——浏览器打开服务器地址即可。

---

## 二、普通用户：浏览器直接使用（最简单）

1. 打开浏览器，访问服务器地址：
   ```
   http://192.168.10.20:8000
   ```
2. 用管理员分配的用户名 + 密码登录
3. 开始使用（创建项目 / 分配任务 / 查看会话）

> 无需安装任何软件。

---

## 三、桌面端（Windows 安装包）

### 安装
1. 双击安装包：`Omnigent Setup 0.9.1.exe`
2. 安装向导中**可选择安装路径**
3. 完成后桌面出现 **Omnigent** 图标

### 连接服务器
1. 打开 Omnigent
2. 在「连接服务器」页面输入地址：
   ```
   http://192.168.10.20:8000
   ```
   （注意：端口是 **8000**，不要填错）
3. 点击「连接」

### 登录
- 输入用户名 + 密码（管理员分配的账号）
- 登录后即可使用完整界面

## 四、Host（执行机）安装

Host 是真正执行 AI 任务的机器。**两种方式任选**：

### 方式 A：Docker（推荐，无需安装 Python 环境）

前置：已安装 [Docker Desktop](https://www.docker.com/products/docker-desktop/)

```powershell
# 启动 host 容器（连接服务器）
docker run -d --name omnigent-host-你的名字 `
  ghcr.io/omnigent-ai/omnigent-host:latest `
  omnigent host --server http://192.168.10.20:8000
```

> host 镜像已内置 omnigent CLI + 全部执行环境（git/tmux/pi 等），免安装。

### 方式 B：本机安装 CLI（Python）

前置：
- Python 3.12+（https://www.python.org/downloads/）
- Git

**步骤 1：安装 omnigent CLI**

有 uv 的话（推荐）：
```powershell
# 安装 uv（首次）
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"
# 安装 omnigent
uv tool install omnigent
```

没有 uv，用 pip：
```powershell
pip install "omnigent"
```

**步骤 2：验证**
```powershell
omnigent --version
```
看到版本号（如 0.9.0）即成功。

**步骤 3：注册为 Host（连接服务器）**
```powershell
omnigent host --server http://192.168.10.20:8000
```

> 首次运行会要求登录服务器账号（用管理员分配的 host 账号）。
> 保持该命令运行 = 这台机器持续作为执行机。

**步骤 4：确认连接成功**
- 打开 Web 界面 → 设置 → 主机
- 应看到这台机器已上线

## 五、常见问题（FAQ）

### Q1: 登录报错「invalid username or password」？
- 确认用户名密码正确
- 密码至少 8 位（服务器要求）
- 找管理员确认账号已创建

### Q2: 连接服务器后「没有主机」？
- 说明还没有 host 执行机注册上来
- 按「第四节」配置一台 host
- 或联系管理员确认 host 是否在线

### Q3: 桌面端提示「无法连接服务器」？
- 确认地址端口正确：`http://192.168.10.20:8000`
- 确认服务器在线（浏览器能打开）
- 确认网络互通（同一局域网）

### Q4: 需要管理员账号？
- 管理员账号：root / 123456（仅管理员使用）
- 普通用户由管理员在「设置 → 成员」中创建

### Q5: 浏览器直接能用吗？
- 能。所有功能都在网页上，桌面端只是壳。
